# Güvenlik kontrol listesi

Bu proje doğrudan internete açılmaya hazır değildir.

- [ ] Girdi uzunluğunu ve türünü doğrula (prototipte var).
- [ ] Hassas müşteri metinlerini/loglarını kaydetmeme (prototipte log saklanmaz).
- [ ] Güvenilmeyen joblib/pickle artefaktı yükleme; kaynağı ve checksum kontrol et.
- [ ] API authentication/authorization, TLS ve rate limiting (ileride).
- [ ] Gerçek müşteri verisi kullanılacaksa KVKK ve veri saklama politikasını belirle.
- [ ] Model skoru kalibrasyonu, OOD testi, insan incelemesi iş akışı (ileride).
- [ ] Veri sızıntısı, class imbalance ve farklı dillerde performans testleri (ileride).
- [ ] Bağımlılık ve container güvenlik taraması (ileride).
